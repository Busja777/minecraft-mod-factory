## Quiet Please 1.0

First release.

- Mutes the game sound files you list by their file ID: `/quiet add 12345 67890` takes one or several IDs at once.
- The game forgets muted sounds when it closes; Quiet Please mutes your list again on every login.
- `/quiet remove 12345` unmutes a file and takes it off the list, `/quiet list` shows the list.
- `/quiet label 12345 text` gives a file your own name, so the list stays readable.
- `/quiet play 12345` plays a file once, to check what it is before you mute it.
- `/quiet off` lets you hear everything again, `/quiet on` mutes your list again. The choice is kept after logout.
- `/quiet errors`, `/quiet emotes` and `/quiet pets` switch the game's error speech, emote sounds and pet sounds on or off.
- The list is shared by all characters of your account. Only whole numbers above 0 are accepted as file IDs.
- Open the help with `/quiet` or `/quietplease`.
