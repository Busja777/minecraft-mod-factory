## Reset Clock 1.1

- Reset Clock now speaks **German**: the countdowns, the timer, the raid warning when it runs out, the window and every answer to a command. On clients in other languages it stays in English.
- The window is a little wider, so the longer German names of the resets fit. In English it looks the same, only with more room.
- The commands and the time letters stay the same in every language, for example `/rc timer 10m` or `/rc cancel`.
- A running timer and the window position from 1.0 are kept.
