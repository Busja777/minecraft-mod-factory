## Junk Butler 1.1

- New **keep list**: grey items on it are never sold. Handy for joke items, keepsakes and grey transmog pieces.
- `/jb keep` followed by an item link (shift-click the item) or an item ID adds it. Several items in one command work too.
- `/jb unkeep` followed by a link or ID takes an item off the list again. `/jb keep` on its own lists everything on it.
- The keep list is shared by all characters of your account, so you only set it up once.
- After a sale, the chat line also says how many items were kept.
