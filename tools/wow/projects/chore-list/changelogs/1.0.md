## Chore List 1.0

First release.

- Your own to-do lists for each character: one for daily chores, one for weekly chores.
- `/chores add daily Feed the pet` or `/chores add weekly World boss` adds a task. Up to 30 tasks per list, 100 characters each.
- `/chores` opens a small window with both lists: tick a task off with its checkbox, remove it with the x button. Drag the window anywhere, its position is remembered.
- At the game's daily reset every daily task is open again, at the weekly reset every weekly task. A reset that came while you were logged out is noticed at your next login.
- The window shows how many tasks are done and when each list resets.
- From chat: `/chores done daily 2` ticks a task off, `/chores remove weekly 1` removes one, `/chores list` shows both lists. `/chorelist` works as well.
