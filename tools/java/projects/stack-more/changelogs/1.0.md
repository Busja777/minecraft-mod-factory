## Stack More 1.0

First release.

- Drinkable potions stack up to 16, water bottles included. Only identical potions stack: effect, duration, strength and name must match.
- Eggs and snowballs stack up to 64 instead of 16.
- Drinking from a stack of potions gives the empty bottle back; with a full inventory it drops at your feet.
- Splash and lingering potions stay at one per slot, and the brewing stand still takes one bottle per slot.
- Needed on the server and on every player's game.
