## Double Door Buddy 1.0

First release.

- Right-click one door of a double door and the other door opens or closes with it.
- A double door is two doors of the same kind side by side, facing the same way, with their hinges on the outer sides, as the game places them.
- The second door takes the state of the clicked one, so a pair that got out of step comes back in step.
- Sneak while clicking with an empty hand to move only the clicked door.
- Iron doors and redstone work as before: only a player's click moves both doors.
- Only the server needs the mod: players without it see both doors move.
