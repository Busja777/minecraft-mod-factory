## Bonemeal More 1.0

First release.

- Bone meal grows sugar cane and cactus by one block on top of the column, up to their natural height of three blocks. Click any block of the column.
- A cactus only grows where the new block could stand, so it never breaks off. Full columns, a block above the top or a cactus that would touch a block use no bone meal.
- Bone meal moves nether wart on by one of its four stages, so fresh wart is ripe after three uses. Ripe wart uses no bone meal.
- Each use takes one bone meal. Dispensers with bone meal work on all three plants too.
- Only the server needs the mod. With it on the client as well, players also see the green sparkles.
