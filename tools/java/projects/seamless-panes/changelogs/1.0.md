## Seamless Panes 1.0

First release.

- Glass blocks and glass panes lose the light frame around every square, so a glass wall or window looks like one clear surface.
- The two small diagonal shine streaks stay on every block, so you can still see where the glass is.
- Built from the vanilla glass texture, pixel for pixel: only the one-pixel frame is cleared.
- The thin edge of a glass pane, stained glass and tinted glass look exactly as before.
- Works on Minecraft: Java Edition 1.21, 1.21.1 and 26.3.
