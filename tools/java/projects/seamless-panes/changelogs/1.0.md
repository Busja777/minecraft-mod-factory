## Seamless Panes 1.0

First release.

- Clear glass loses its frame lines: walls and windows of glass blocks look like one clean surface instead of a grid.
- Glass panes use the same texture for their faces, so they lose the frame too. The thin pane edge stays as it is.
- The small diagonal highlights stay, so you can still see where the glass is.
- The glass shell of the beacon uses this texture as well and looks clearer.
- Stained and tinted glass are not changed yet.
- Works on Minecraft 1.21, 1.21.1 and 26.3.
