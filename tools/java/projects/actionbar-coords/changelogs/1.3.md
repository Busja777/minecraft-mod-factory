## Actionbar Coords 1.3

Coordinates only, if you like it short.

- New: a compact line that shows only your coordinates, for example `X 120  Y 64  Z -33`, without the direction and the clock.
- `/trigger coords set 3` switches between the compact line and the full line. Each player picks their own; no operator rights needed.
- The compact line keeps the colour style you picked with `/trigger coords set 2`.
- Any other number, for example `/trigger coords set 9`, now explains all three: 1 shows or hides the line, 2 picks the next colour style, 3 switches the compact line on or off.
- Everyone keeps the full line until they switch, so nothing changes unless you want it to.
- Works on Minecraft 1.21, 1.21.1 and 26.3.
