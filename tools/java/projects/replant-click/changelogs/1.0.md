## Replant Click 1.0

First release.

- Right-click a fully grown wheat, carrot, potato or beetroot crop to harvest it and replant it in one go.
- The loot is the same as breaking the crop with the item in your hand, so Fortune works. One seed of it is planted again.
- Sneaking turns it off, so you can still place blocks next to crops. Bone meal keeps its normal use.
- Only the server needs the mod: players without it still harvest with a right-click.
