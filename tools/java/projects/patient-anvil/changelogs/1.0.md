## Patient Anvil 1.0

First release.

- The anvil no longer refuses repairs and enchantment combinations that cost 40 levels or more.
- The cost is the vanilla cost, including the growing prior work penalty; the player needs and pays all of it.
- Enchanting a stack of more than one item stays refused, as in vanilla.
- On a server only the server needs the mod: players without it see "Too Expensive!" in red, but can still take the result if they have the levels. With the mod on the client, the screen shows the real cost.
