## Join Greeter 1.0

First release.

- Players who join the world for the first time get a welcome line, players who come back get a welcome-back line, a second after vanilla's "joined the game".
- Optional rule lines follow the welcome for newcomers, or on every join with `rulesEveryJoin`.
- Optional starter kit for first-time players: item ids and counts in `starterKit`. It is empty by default, so nothing is given until you set it.
- Colours and styles with `&` codes (`&0` to `&f`, `&l`, `&o`, `&n`, `&m`, `&k`, `&r`) or the section sign, and the placeholders `{player}` and `{online}`.
- "First time" is read from the player's own statistics in the world, so players from before the install are greeted as returning players.
- Everything is set in `config/joingreeter.json`, created on the first start. Only the server needs the mod.
