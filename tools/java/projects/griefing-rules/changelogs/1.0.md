## Griefing Rules 1.0

First release.

- Five new gamerules in the Mobs category: `creeperGriefing`, `ghastGriefing`, `witherGriefing`, `endermanGriefing` and `ravagerGriefing`. Each one switches off the block damage of one kind of mob, while `mobGriefing` stays on for everything else.
- Creeper, ghast fireball and wither explosions still hurt and push players and mobs; only the blocks stay. Ghast fireballs light no fire.
- `witherGriefing` also covers the blocks the wither breaks around itself when hurt and the wither roses it plants (the rose drops as an item instead).
- All rules are on by default, so nothing changes until you switch one off. `mobGriefing false` still turns everything off.
- Only the server needs the mod: players can join without installing anything.
