## Fast Leaf Fall 1.1

Speed settings.

- New file `config/fastleaffall.json`, created on the first start. Without changes leaves fall exactly as fast as in 1.0.
- `minDelayTicks` and `maxDelayTicks` (defaults `10` and `49`, 20 ticks are one second): each leaf that lost its tree waits a random time between the two before it decays. Lower them for an even faster fall, raise them (up to `400`) for a slower one.
- `leavesPerTick` (default `64`, from `1` to `512`): how many leaves may decay per world and tick. Lower it on busy servers to spread the work over more ticks.
- A value out of range falls back to its default with a warning in the server log; a maximum below the minimum uses the minimum for both.
- Everything from 1.0 stays the same.
