## AFK Tag 1.0

First release.

- A player who stays idle for 5 minutes gets a grey `[AFK]` in front of their name in the player list, and the chat says "<name> is now AFK".
- Moving, looking around, chatting, running a command or using, breaking or clicking anything clears the tag at once, and the chat says "<name> is back".
- Drifting in water, riding without steering and being teleported do not count as being active.
- The idle time is set in `config/afktag.json` (1 to 1440 minutes); the file is created on the first start.
- Only the server needs the mod: players without it see the tag and the messages too.
