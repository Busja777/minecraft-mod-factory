## AFK Tag 1.2

The player list shows how long someone has been away.

- An AFK player's tag now includes their idle time, for example `[AFK 12m]` or `[AFK 1h 5m]`. The time counts from the player's last input, so with the default setting the tag appears as `[AFK 5m]`.
- The time goes up once a minute; the player list is only sent again when the shown minutes change, not every tick.
- When the player comes back, the tag and the time disappear at once, as before.
- New setting `showAfkTime` in `config/afktag.json` (default `true`). Set it to `false` to get the plain `[AFK]` tag of 1.1. Config files from 1.0 and 1.1 keep working; without the setting the default is used.
- Only the server needs the mod: players without it see the time too.
- Everything from 1.1 stays the same.
