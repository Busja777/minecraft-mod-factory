## AFK Tag 1.1

AFK players no longer keep everyone else awake.

- When the server checks whether enough players are asleep to skip the night (the `playersSleepingPercentage` rule), players marked AFK count as neither sleeping nor needed, just like spectators. Two players online, one asleep and one AFK: the night is skipped.
- The "x/y players sleeping" message counts the same way, and going AFK or coming back updates it at once.
- New setting `ignoreAfkForSleep` in `config/afktag.json` (default `true`). Set it to `false` to count AFK players again. Config files from 1.0 keep working; without the setting the default is used.
- Everything from 1.0 stays the same.
