## Owner Safe Pets 1.1

Settings.

- New file `config/ownersafepets.json`, created on the first start. Without changes everything works exactly like 1.0.
- `sneakToHit` (default `false`): set it to `true` and you can hurt your own pet while sneaking, for example to put down a sick animal. Only your own hits count; your arrows and explosions stay harmless to your pets.
- `protectFromOwnerExplosions` (default `true`): set it to `false` and TNT you lit or crystals you hit can hurt your pets again.
- A broken value falls back to its default with a warning in the server log.
- Everything from 1.0 stays the same.
