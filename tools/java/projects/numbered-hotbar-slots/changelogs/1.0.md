## Numbered Hotbar Slots 1.0

First release.

- Each hotbar slot shows a small number from 1 to 9 in its top-left corner, so you see which number key picks which slot.
- Light grey digits with a dark shadow, readable on the dark slots.
- The numbers sit in the corner that tools and weapons leave free; the item count and the durability bar stay where they were.
- Only the hotbar picture changes, nothing else in the game looks different.
- Works on Minecraft 1.21, 1.21.1 and 26.3.
