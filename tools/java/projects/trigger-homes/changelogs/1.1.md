## Trigger Homes 1.1

Up to three homes.

- `/trigger sethome set 2` and `/trigger sethome set 3` save a second and a third home; `/trigger home set 2` and `/trigger home set 3` take you there.
- `/trigger sethome` and `/trigger home` still mean home 1, so nothing changes if you only need one.
- Your home from 1.0 is kept as home 1, also for players who are offline during the update.
- Each home can be in the Overworld, the Nether or the End; a new home 2 only replaces home 2.
- All homes and `/trigger spawn` share the 30-second cooldown, as before.
- Works on Minecraft 1.21, 1.21.1 and 26.3.
