## Trigger Homes 1.3

A list of your homes.

- New: `/trigger homes` lists the homes you have set, one line each with the coordinates, the dimension and the command that takes you there, for example `Home 2: 120 64 -33 in the Nether (/trigger home set 2)`.
- Without any home it says so and tells you how to set one.
- If you have to wait before the next teleport, the list also shows the seconds left.
- A last line reminds you of the commands: `/trigger home`, `/trigger sethome`, `/trigger back` and `/trigger spawn`.
- `/trigger homes` does not teleport you and does not start the 30-second cooldown. Like the other commands, it needs no operator rights.
- Your homes from 1.0, 1.1 and 1.2 are kept.
- Works on Minecraft 1.21, 1.21.1 and 26.3.
