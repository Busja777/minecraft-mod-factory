## Fresh Splashes 1.0

First release.

- 300 new splash texts for the title screen, about mining, mobs, crafting, building, farming, redstone, exploring, the Nether and the End.
- Every line is written for this pack; it replaces the vanilla splash list while the pack is turned on.
- Works on Minecraft 1.21, 1.21.1 and 26.3 with the same zip.
