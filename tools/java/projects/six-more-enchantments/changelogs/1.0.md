## Six More Enchantments 1.0

First release.

- Six new enchantments from the enchanting table, for Minecraft 1.21, 1.21.1 and 26.3.
- Reach I–II for pickaxes, axes, shovels and hoes: half a block more reach per level.
- Stepping for boots: walk up full blocks. Leaping I–II for boots: higher jumps and one block more safe fall per level. The two exclude each other.
- Vitality I–II for chestplates: one extra heart per level, instead of a protection enchantment.
- Swiftness I–II (5% faster walking per level) or Steadfast I–II (10% less knockback per level) for leggings.
- Not in chest loot, villager trades or mob gear.
