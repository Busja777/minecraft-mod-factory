## Villager Birthday Reminders 1.4

The setting is now in German too.

- The "DayBefore" switch has a readable name and description in the in-game config menu (Generic Mod Config Menu): "Reminder the day before" in English, "Erinnerung am Vortag" in German. Players with the game set to German see the setting in German; everyone else keeps the English one.
- Same letters, same gift ideas, same dates; your setting carries over and nothing else changes.
