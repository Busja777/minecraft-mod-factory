## Robin's Fair Prices 1.1

The settings are now in German too.

- The cost setting has a readable name, description and value names in the in-game config menu (Generic Mod Config Menu): "Building cost" (75 %, 50 % (half), 25 % (a quarter)) in English, "Baukosten" in German. Players with the game set to German see the setting in German; everyone else keeps the English one.
- Same buildings, same costs and construction days; your setting carries over and nothing else changes.
