## Generous Geodes 1.1

The settings are now in German too.

- The level setting has a readable name, description and level names in the in-game config menu (Generic Mod Config Menu): "Geode generosity" with Gentle (60 %), Generous (70 %) and Lavish (80 %) in English, "Großzügigkeit der Geoden" with Sanft, Großzügig and Üppig in German. Players with the game set to German see the setting in German; everyone else keeps the English one.
- Same levels, same chances; your setting carries over and nothing else changes.
